# G2211 Rubric Signals

Extract the following signals as YES/NO based on the encounter note:

- is_preventive_visit
- administrative_new_patient
- longitudinal_evidence
- chronic_conditions_managed_today
- medication_stewardship
- inherent_complexity
- acute_issue_only
- heavy_diagnostic_workup

Definitions:
- Managed today requires treatment decisions or risk-based deferral with clinical reasoning.
- Medication stewardship includes initiation, adjustment, or informed non-initiation with clinical reasoning.
- Inherent complexity includes constrained or staged management.
- Administrative new patient reflects billing status only and does not block G2211 if longitudinal care responsibility is clearly established.

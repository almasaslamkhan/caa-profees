# Documentation Standards

Use these rules when linking diagnoses to E/M or procedures.

- **Main Reason for Visit**: Include the diagnosis, condition, problem, or reason for visit that the note shows was chiefly responsible for the outpatient encounter.
- **Other Current Conditions**: Include additional current conditions only when the note shows they required or affected care, treatment, or management during the encounter.
- **No Uncertain Diagnoses**: Do not code probable, suspected, possible, rule out, questionable, likely, or similar uncertain diagnoses in the outpatient setting; when no confirmed diagnosis is established, code the documented symptom, sign, abnormal finding, or other reason for the visit.
- **No Medication-Only Coding**: Do not code a diagnosis solely from the presence of a medication unless the note shows the related condition is current and relevant to the encounter.
- **Highest Specificity**: Use the most specific diagnosis supported by documentation, including site, laterality, acuity, chronicity, stage, severity, manifestation, encounter type, and subtype when documented.
- **Supported Z-Codes Only**: Assign history, status, screening, counseling, follow-up, aftercare, preventive, measurement, noncompliance, immunization, device/status, or medication-use Z-codes only when the note clearly supports their use for the encounter.
- Treat this as professional-fee association coding; do not assign facility diagnoses or broaden associations beyond the documented professional service.
- Use only the Assessment and Plan (A/P) section to justify associations.
- Use order narratives only to justify lab/procedure indications.
- Require explicit documentation linking a diagnosis to the service.
- Avoid inferential or assumed links when documentation is ambiguous.
- Link only diagnoses assessed, managed, or followed up during the current encounter.
- Preserve all input codes exactly; do not add, remove, or alter E/M or procedure codes.
- Use only diagnoses already present in the input diagnosis list.
- When the prompt provides active candidate diagnoses, link only those candidate diagnoses that are current, documentation-supported, and directly support the specific charge.
- Provide concise, non-leading justification tied to documentation.
- Order linked diagnoses by medical-necessity strength (primary first).
- Mark only the strongest diagnosis as primary for each charge.
- Avoid shotgun association; do not attach every active diagnosis to every charge.
- If no clearly supported diagnosis association exists for a charge, return an empty linked diagnosis list rather than guessing.

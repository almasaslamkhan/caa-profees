# Labs, Diagnostics, and Procedures

Use these rules for lab, diagnostic, or procedural associations.

- Associate a diagnosis to a lab or procedure only when the A/P or order narrative states it as the indication.
- If a test or procedure is ordered for multiple diagnoses, link all explicitly documented indications.
- Do not link procedures to diagnoses based on generic references like "labs" or "blood work."
- Link venipuncture or collection codes only to diagnoses explicitly tied to the lab order.
- Associate procedures only when performed and documented during the current encounter at the reporting location.
- Do not link historical or offsite procedures unless the note documents them as performed in this encounter.

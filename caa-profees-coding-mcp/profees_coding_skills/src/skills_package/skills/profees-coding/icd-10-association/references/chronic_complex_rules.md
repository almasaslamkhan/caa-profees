# Chronic and Complex Conditions

Apply these rules when linking chronic, complex, or longitudinal care diagnoses.

- Link chronic or complex diagnoses only when the A/P documents active management, therapy review/titration, or risk stratification for the condition.
- Treat terms like "stable," "continue therapy," or "routine follow-up" as sufficient evidence when the A/P shows ongoing management.
- Do not link diagnoses based only on problem list, history, or medication list without A/P activity.
- For G2211, link diagnoses only when the A/P documents longitudinal care needs such as goal setting, care coordination, or ongoing disease management.
- Prefer diagnoses that represent the active clinical drivers of care in the current encounter.

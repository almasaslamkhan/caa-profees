# Preventive and Screening Associations

Use these rules for preventive services and screening diagnoses.

- Link preventive Z-codes only to preventive E/M services when the A/P documents a wellness exam or screening.
- For encounters with both preventive and problem-oriented E/M, link screening and risk-factor Z-codes to the preventive E/M and link active problems to the problem-oriented E/M.
- Link risk-factor or family history Z-codes only when the A/P shows they were assessed or managed in the encounter.
- Do not link preventive or screening Z-codes to procedures unless the order narrative or A/P explicitly states the screening indication.

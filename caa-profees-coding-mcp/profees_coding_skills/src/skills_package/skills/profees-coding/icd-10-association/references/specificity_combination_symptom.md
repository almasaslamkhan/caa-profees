# Specificity, Combination, and Symptom Rules

Apply these rules when selecting among related diagnoses.

- Link the most specific diagnosis supported by documentation; avoid linking both specific and nonspecific versions unless separately managed.
- If a combination code captures the documented condition, link the combination code alone unless the A/P documents distinct management of components.
- Link a symptom diagnosis only when the A/P documents assessment or management of the symptom and no definitive diagnosis is established.
- Avoid duplicate or overlapping links for the same clinical concept.
- Do not link resolved, historical, or status-only diagnoses unless the A/P documents current management.
- Do not link external cause or personal history Z-codes to services unless the A/P explicitly documents them as the reason for the service.

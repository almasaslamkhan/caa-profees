# Capability Overview

## Summary
This capability shows professional-fees coding recommendations for ambulatory clinical encounters. When the user types **show codes**, **show ambulatory coding**, or **show ambulatory codes** in the physician assistant chat, the ProFees MCP tool generates coding suggestions and opens the editable **Generated codes** A2UI canvas.

The canvas displays E/M, preventive care, CPT procedure, HCPCS and modifier recommendations for coder or clinician review. From the canvas, the user can use **Recode** after note changes or **Submit codes** when ready.

## User problem
Professional-fee coding requires physicians and clinical teams to review supported E/M levels, procedures, HCPCS add-ons, diagnoses, linked diagnosis and modifiers from encounter documentation. Doing that manually is slow, error-prone, and hard to review consistently across notes. This capability gives physicians a structured coding summary and an editable generated-codes canvas so they can review suggested codes more efficiently before downstream billing review.

## Target users
The primary users are physicians working in ambulatory encounter workflows who need to review AI-generated professional-fee coding suggestions.

## Business value
The capability reduces manual coding effort, improves consistency of professional-fee code review, and helps physicians act on coding suggestions while the encounter context is still available. It supports faster review of generated codes before downstream billing review.

## Supported user journeys

- Type **show codes**, **show ambulatory coding**, or **show ambulatory codes** in PPCA chat to open the **Generated codes** canvas.
- Render generated E/M, preventive care, modifier, time, and linked-diagnosis selections in the `Generated codes` canvas.
- Use **Recode** after the visit note or payload changes.
- Review suggested CPT, HCPCS, ICD-10-CM, diagnosis association, and modifier outputs before downstream billing action.
- Use **Submit codes** to submit selected generated codes from the canvas.

## Out of scope

- Do not use this skill for inpatient facility coding.
